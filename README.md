# OOP-Project
# 1. PROJECT TITLE
AI-Based Classroom Noise Detection & Alert System
# 2. PROJECT INTRODUCTION
This project is a smart classroom monitoring system developed using Python and Object-Oriented Programming (OOP).
The system automatically:
monitors classroom noise levels
detects excessive sound
generates alerts
stores analytics data
This helps maintain:
classroom discipline
concentration
better learning environment
# 3. OOP CONCEPTS USED
OOP Concept

Encapsulation
Protecting data inside classes
Abstraction
Hiding microphone complexity
Inheritance
Future alert systems
Polymorphism
Different alert behaviors
Composition
Classes working together
# Purpose
Provision of smooth class room environment to students.
